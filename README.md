# Cloud 9 hackathon: team vault

Shared notes for the AmaliTech × AWS hackathon team (ERP Migration Progress Portal): decisions, session logs, references, workflow notes and open follow-ups. It is an [Obsidian](https://obsidian.md) vault.

- **Code and the canonical team plan** live in the main repo, `Amali-Tech/cloud-9-hackathon` (`docs/TEAM_PLAN.md`, `DECISIONS.md`). If a note here disagrees with the repo, the repo wins; `04 Reference/Team plan.md` is a generated copy.
- **Start here:** `00 Home.md`, then the latest note in `03 Sessions/` (its first line is the next command) and `Open follow-ups.md`.
- **AI assistants:** read `00 Home.md`, `05 Workflow/Working with AI assistants.md` and today's session note before helping a teammate.

## Use it
1. `git clone git@github.com:patrick-appiah/aws-hackathon-agent-context.git`
2. In Obsidian: *Open folder as vault* and pick the cloned folder.
3. `git pull` before you start, then commit and push small changes. New notes start from `99 Templates/`.

## Rules
- No secrets: no keys, tokens or passwords. Synthetic data only; refer to people by role in decisions.
- Record decisions in `01 Decisions/` (from the template) and add a row to `01 Decisions/Decisions.md`.
