# global profiles can leave the EU
`global.*` inference profiles can route requests outside the region; `eu.*` keep them in the EU.

**Why:** Region gate: data must stay in the agreed region or the team is disqualified.
**How to apply:** Only ever configure `eu.*` model IDs.
