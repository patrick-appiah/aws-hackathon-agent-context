# First Bedrock call auto-subscribes via Marketplace
Invoking a third-party model the first time creates an AWS Marketplace subscription and sends an email. Pay-per-token only, no fixed fee.

**Why:** Current Bedrock access model.
**How to apply:** Expect the email; it's harmless. Tell organisers if they ask.
