# Repo change history is graded
The repo reviewer (50/100 points) "also checks the history of changes".

**Why:** [[Pitch track grading rubric]] (GitHub repo section).
**How to apply:** Commit early and often, with meaningful messages, from Day 1. Don't squash everything into one end-of-day commit. Push to GitHub as soon as the repo name is settled.
